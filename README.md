# password-strength-checker
## Overview
A beginner‑friendly Python tool that analyses a password and gives it a strength rating based on length, character variety, dictionary word detection, and common weak password patterns. This project teaches secure coding fundamentals and basic cybersecurity concepts.


## 🚀 Features
- Checks password length
- Detects uppercase, lowercase, numbers, and symbols
- Flags common weak passwords
- Detects dictionary words inside the password
- Generates a strength score(Weak/Medium/Strong)
- Provides clear recommendations
- Fully commented code
- No external libraries required


## 🔍How It Works
The checker evaluates the password using several criteria:
1. Length check
2. Character variety
3. Weak password detection
4. Dictionary word detection
5. Score calculation
6. Final strength rating
This helps users understand how their password is and how to improve it.

## 🖥️ Usage
- Run the script
- Enter a password
- View the strength rating and recommendations

## 📂 Code Overview
The script uses:
- re.search() → pattern matching
- Lists → weak passwords + dictionary words
- Scoring system → evaluates password strength
- Feedback list → stores recommendations
The code is fully commented so as to explain each step clearly.
